# ADR-0027: Thinking-partner folder

Status: accepted · Date: 2026-11-05 · Decided by: founder (F-4)

## Decision

`docs/thinking-partner/` (`NOW.md`, `relays/`, `briefs/`, `LOG.md`, `OPEN.md`) is updated in the same PR as each step's work, one section per activity, under about 20,000 words, judge-safe and secret-free. `OPEN.md` is the founder's only to-do list.

## Why

The founder's planning partner on the web reads only files in the public repo.

## Consequences

Main keeps the top summaries; each session owns its own sections and relay.
