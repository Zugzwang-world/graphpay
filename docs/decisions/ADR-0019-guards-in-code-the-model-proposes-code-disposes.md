# ADR-0019: Guards in code: the model proposes, code disposes

Status: adopted from the lab (planning/DECISIONS.md part A) · Date: 2026-11-05 · Decided by: founder (pre-event) · Source: `planning/DECISIONS.md` part A, row 0019

## Decision

Guards in code: the model proposes, code disposes (limits from the human's words, ranking recomputed in code, payer bound to the approved order, single-flight payment, client spend controls)

## Why

A prompt can be ignored, injected or hallucinated around; money must not depend on it
