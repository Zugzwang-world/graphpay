# ADR-0018: graphpay.eth registered bare before the event

Status: adopted from the lab (planning/DECISIONS.md part A) · Date: 2026-11-05 · Decided by: founder (pre-event) · Source: `planning/DECISIONS.md` part A, row 0018

## Decision

`graphpay.eth` was registered bare on real Sepolia before the event (owner OPERATOR, no resolver, no records, no registry); everything under it is created at the event

## Why

Anyone could take the name first; registering bare keeps all namespace work inside the event
