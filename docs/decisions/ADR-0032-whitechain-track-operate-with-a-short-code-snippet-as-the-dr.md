# ADR-0032: Whitechain track: Operate, with a short code snippet as the drop-in

Status: accepted · Date: 2026-11-05 · Decided by: founder (chat, 21:40 and 21:42 IST)

## Decision

We enter Whitechain's Operate track. The drop-in is a short code snippet that the separate demo store (`graphpay-store`, M16) integrates in about 20 lines. GraphPay itself stays a general Whitechain payments solution: nothing in code is hard-coded to one prize track.

## Why

Operate asks for a drop-in in a separate demo app and both merchant and customer views; the public prize page sets no limit on tracks, so a general product keeps other tracks open.

## Consequences

Track wording appears only in the sponsor files and the submission text (M17).
