# ADR-0012: Agent to agent over plain HTTP x402 with a signed mandate

Status: adopted from the lab (planning/DECISIONS.md part A) · Date: 2026-11-05 · Decided by: founder (pre-event) · Source: `planning/DECISIONS.md` part A, row 0012

## Decision

Agent-to-agent: plain HTTP x402 (free quote, 402 on pay and re-order), the mandate hash signed into the witness and stored on the order; static agent card and UCP files (not built)

## Why

Simplest interoperable flow; the mandate makes the human's limit verifiable
