## Gotchas learned (also in `docs/problems/PROBLEM_LOG.md` P-identity-1)
- The public Sepolia RPC is load balanced: read-after-write can hit a lagging node. Use `retryingReads`, wait with `eventually`, poll receipts with `getTransactionReceipt` (viem's `waitForTransactionReceipt` timed out on anvil). A read error must fail closed (`ENS_READ_FAILED`), and must not be cached.
- Anvil fork: `anvil --fork-url https://ethereum-sepolia-rpc.publicnode.com --fork-block-number <head-10> --auto-impersonate --port 8611` (a fork at the latest block fails "block not found"); impersonated signers need `anvil_setBalance` (default tip is 1 gwei). Provision it with `node scripts/ens/real-run.mjs --fork http://127.0.0.1:8611 --disposable 1 --out <scratch file>` (loopback `127.0.0.1` only; `--out` keeps the committed `namespace.json` untouched). Fork keys are public: never mirror a fork result to a real policy or Arkiv.
- Node: `fnm exec --using=22.23.4 <cmd>`. No `timeout` command on this Mac: use `perl -e 'alarm N; exec @ARGV'`.
- GitHub is slow from this Mac: push with `git -c http.lowSpeedLimit=100 -c http.lowSpeedTime=60 push` in a retry loop (up to 6, 15 s apart); `gh` calls need retries too; write PR bodies to a file; `git push` and `gh pr create` as separate commands.
- On merge conflicts in `docs/decisions/README.md`, `PROBLEM_LOG.md`, `FACTS.md`, `NOW.md`, `LOG.md`, `OPEN.md`: keep both sides; take main's `pnpm-lock.yaml` and re-run `pnpm install`. ADR numbers: take the next free one after `git fetch` (0059 is mine; others may have taken more).
- Never print or read `.env`; scripts print addresses and hashes only. The reviewer agent has run once (M5); its blocking item (a re-run rewrote status/cap) is fixed.
- Real-chain spend so far: OPERATOR ~0.095 ETH untouched at 19–21 wei gas. Sepolia is effectively free.
