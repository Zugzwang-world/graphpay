## The thinking-partner folder (`docs/thinking-partner/`)

The founder's thinking partner (Claude on the web) knows only what this folder says. Every session keeps it current, and **its updates ride in the same PR as the step's work**. It is the founder's single to-do list too: the event repo has no `docs/operator/OPERATOR_QUEUE.md` and no `docs/plan/NOW.md`.

| file | what goes in it |
|---|---|
| `NOW.md` | One page: updated time (IST), where we are in plain words, what's running, blockers, next. A short top summary (main only), then **one fixed section per activity**; each session rewrites only its own section at the end of every step |
| `relays/<activity>.md` | One per activity, named after the worktree or activity: `foundation`, `payments`, `identity`, `arkiv`, `agents`, `integration`, `website`, `records`, `submission`. About 800 words, plain language first, then technical. Overwritten each step |
| `briefs/` | Every brief the founder attaches, saved on receipt as `briefs/<HHMM>-<slug>.md`. A pack prompt (already in `planning/PROMPTS/`) gets a one-line pointer file instead of a copy |
| `LOG.md` | One line per PR: time (IST), activity, result, PR link. **Append-only, under your activity's heading**; only main (M14) rolls older lines into a dated summary at the top and keeps the last 60 |
| `OPEN.md` | The founder's to-dos and open questions, each with what, where, why and a recommendation: a "founder now" list at the top (main only), then one section per activity |

Rules: the whole folder stays under about 20,000 words (check with `wc -w`). No secrets, no key-shaped strings, no private URLs; judge-safe wording, because the repo is public. Every session owns its sections of `NOW.md`, `LOG.md` and `OPEN.md` and its own `relays/<activity>.md` (add `docs/thinking-partner/` to each session's owned folders). After the last push, **watch the PR until it merges**; on a conflict, merge `origin/main` again, keep every line, and push.

## Pitfalls
- Deny rules take effect mid-session and also block Write/`ls`/`cat` on `.env`: create `.env` only through scripts.
- `vercel git connect` fails on a new repo until the founder grants access (`SPEC/SECURITY_AND_OPS.md` §6).
- Auto-merge can take about 4 minutes; `gh pr merge --auto` right after a push may need a second try.
- New `.claude/skills/` needs `/reload-skills`; new `.claude/agents/` needs a restart: use general-purpose subagents with the agent text until then.
- Never print a key; never put one on a command line. A generator that filled every missing role at once minted clashing keys twice in the lab: one role per run.
- The lab's `.env` also holds lab-only role keys (FACILITATOR, PAYER, …). The import allowlist keeps them out; never widen it.
- A hardcoded 21,000 gas limit failed on Sepolia on 2026-11-05 (a transfer to a new account needs about 207,000): estimate gas for every transaction.
