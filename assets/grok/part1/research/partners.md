# Partner evidence and claim boundaries

Research window: 1 May–6 November 2026. Checked 6 November 2026 (IST). Dates below distinguish publication dates from access dates. A live, undated page is not evidence of an in-window announcement. No source below endorses GraphPay.

## ENS

- **IN WINDOW — 2026-05-15:** The ENS DAO newsletter describes .eth names and subnames as durable, resolvable agent identity and discusses ENSIP-25/26 with ERC-8004. [ENS DAO Newsletter 112](https://discuss.ens.domains/t/ens-dao-newsletter-112-5-15-2026/22128). This is ecosystem commentary, not proof of universal adoption or a security audit.
- **IN WINDOW — 2026-05-06:** An implementation author describes an ENS-bound agent with registration, discovery, a signed manifest and scoped wallet authority. [ENS-bound agent implementation](https://discuss.ens.domains/t/reference-implementation-of-an-ens-bound-agent/22100). It is the author's implementation report, not an ENS guarantee of personhood or honesty.
- **BACKGROUND; OUTSIDE WINDOW — created 2025-10-02:** ENSIP-25 specifies a parameterized text-record check for the relationship between a name and a registry identity; the opened document is marked draft. [ENSIP-25](https://docs.ens.domains/ensip/25/). Name ownership changes can make old attestations stale. Do not describe this as finalized merely because it has an ENSIP number.
- **GraphPay boundary:** ENS may publish payout and policy records, but a text record alone does not enforce a spending cap or revoke a wallet signature. GraphPay's record keys, resolver choice, cache policy and actual enforcement are **UNVERIFIED** without code or transaction evidence.

## Arkiv

- **IN WINDOW — 2026-07-29:** Arkiv announced a stack rebuild, richer entity attribute types and retirement of Braga. [Arkiv architecture update](https://arkiv.network/blog/braga-sunsets-arkiv-keeps-building). This is a dated announcement; it does not prove the later network's availability.
- **CURRENT EVENT PAGE — publication date UNVERIFIED; accessed 2026-11-06:** The Mumbai prize page describes wallet-owned entities, SQL-like filters and chosen expiration, and explicitly suggests agent tasks, bids and claims as ephemeral coordination state. [Arkiv Mumbai prize brief](https://ethglobal.com/events/mumbai/prizes/arkiv). In-window publication date is **UNVERIFIED**.
- **UNDATED; accessed 2026-11-06:** Arkiv Hub lists Cortex as agent memory with observations whose lifetime can be extended when useful. [Arkiv ecosystem](https://hub.arkiv.network/ecosystem). This is an ecosystem listing, not independent evaluation. Publication date and in-window eligibility are **UNVERIFIED**.
- **GraphPay boundary:** The application can model payment relationships in Arkiv entities. These sources do not establish a native graph database traversal engine, a universal 2-read query, or a speed advantage. “2 reads against about 48” is a GraphPay demo claim, **UNVERIFIED** until the team supplies queries, pagination rules, data snapshot and read-count trace.

## Whitechain

- **UNDATED; accessed 2026-11-06:** Whitechain's Agent Skills documentation describes a testnet developer playbook for network setup, deployment, verification and inspection; token transfers, swaps, message signing and bridging are explicitly outside that skill's scope. [Whitechain Agent Skills](https://docs.whitechain.io/build-with-ai/claude-skills). Publication date and in-window eligibility are **UNVERIFIED**.
- **UNDATED; accessed 2026-11-06:** Whitechain documents execution and L1 data fees paid in WBT. [Whitechain fees](https://docs.whitechain.io/learn/network/network-fees.md). Its dollar examples are illustrative, not guaranteed prices. Publication date and in-window eligibility are **UNVERIFIED**.
- **GraphPay boundary:** “The agent pays no gas” requires an application-specific sponsor, relayer or other demonstrated arrangement; it must not become “Whitechain has no gas fees.” The one-signature payment flow, sponsor, test USDT contract, renewal authority and replay protection are **UNVERIFIED** without implementation evidence. No dated in-window Whitechain statement specifically endorsing autonomous agent payments was confirmed in this research.

## Swarm

- **IN WINDOW — published 2026-11-02; reports a 2026-10-29 call:** Swarm reports Datafund's preview of PLUR.ai with hash-chained agent memory and verifiable Swarm references. [Swarm October call recap](https://www.ethswarm.org/blog/2026/swarm-community-call-29-october-recap/). The page says the preview's public release was expected in November; do not present that expectation as a completed release.
- **IN WINDOW — same source and publication date:** Swarm distinguishes the integrity of recorded memory from proof of why an AI produced an answer. One-line summary: provenance supports independent checks on records, not proof that their contents are true. [Swarm provenance discussion](https://www.ethswarm.org/blog/2026/swarm-community-call-29-october-recap/).
- **GraphPay boundary:** Public menus and synthetic photos fit the storage role in the brief. Real refund evidence can contain private data: redact before public upload, define retention and access policy, and do not promise that a content hash proves a physical delivery happened.

## Presentation claims requiring GraphPay evidence

The brief supplies synthetic shops, prices and performance figures; none is real-world market evidence. Also **UNVERIFIED**: the 2-versus-about-48 read comparison, 17-line checkout integration, one-signature flow, no-agent-gas mechanism, same-SDK cab payment, pause/resume/revocation enforcement, refund execution and weekly renewal. Preserve them as demo claims only, pending a reproducible code or transaction reference from the team. No third-party citation in this file validates them.
